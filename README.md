# 📸 PixelFeed

**PixelFeed** is a modern, production-ready, full-stack social media web application inspired by Instagram. Built using the **MERN Stack** (React.js, Node.js, Express.js, MongoDB) and powered by **Redux Toolkit**, it features a fully responsive, pixel-perfect user interface and implements local data persistence with **IndexedDB** for seamless performance and offline resilience.

---

## 🚀 Key Features

- **Full-Stack Authenticated System:** Secure user registration and login with JWT and robust session management.
- **Dynamic Content Feed:** Create, read, update, and delete image posts with captions and tags.
- **Real-Time Interactions:** Like, unlike, and comment on posts with dynamic state updates via Redux Toolkit.
- **Local-First Architecture:** Integrated with IndexedDB to cache user feeds and persistent states locally for instant loading and offline data resilience.
- **Advanced State Management:** Global state distribution handled seamlessly across components using Redux Toolkit.
- **100% Responsive Design:** Tailored layouts optimized for mobile viewports, tablets, and desktop setups.

---

## 🛠️ Tech Stack

### Frontend
- **Framework:** React.js
- **State Management:** Redux Toolkit & React Context API
- **Local Persistence:** IndexedDB
- **Styling:** Tailwind CSS / Modern CSS3

### Backend
- **Environment:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB (via Mongoose)
- **Authentication:** JSON Web Tokens (JWT) & bcrypt
